# 콘솔 실행 증빙

Python 3.12.14로 프로젝트를 임시 폴더에 복사해 검증했습니다. 각 발췌는 실제 콘솔 입출력에서 관련 줄을 옮겼습니다.

## 숫자 및 빈 입력 검증

메뉴에 빈 줄, abc, 9, 양쪽 공백이 있는 3을 차례로 입력했습니다. 마지막 입력은 문제 목록을 열었습니다.

```text
선택:
입력 오류. 1~5 사이의 숫자를 입력하세요.
선택: abc
입력 오류. 1~5 사이의 숫자를 입력하세요.
선택: 9
범위 오류. 1~5 사이의 숫자를 입력하세요.
선택:  3
등록된 퀴즈 목록 (5개)
선택: 5
```

첫 문제의 답으로 빈 줄, abc, 0, 양쪽 공백이 있는 2를 입력했습니다.

```text
정답 번호 (1-4):
입력 오류. 1~4 사이의 숫자를 입력하세요.
정답 번호 (1-4): abc
입력 오류. 1~4 사이의 숫자를 입력하세요.
정답 번호 (1-4): 0
범위 오류. 1~4 사이의 숫자를 입력하세요.
정답 번호 (1-4):  2
정답입니다!
```

등록 중 빈 문제와 공백만 있는 첫 선택지도 재입력을 요청했습니다.

```text
문제:
내용을 입력하세요.
문제: 지구의 대기에서 가장 많은 기체는?
선택지 1:
내용을 입력하세요.
선택지 1: 산소
```

## 재실행과 저장 검사

문제 1개를 등록하고 6문제 중 5문제를 맞혀 83점을 저장했습니다. 종료 뒤 다시 실행해 메뉴 3과 4를 선택했습니다.

```text
저장된 데이터를 불러왔습니다. 퀴즈 6개
선택: 3
등록된 퀴즈 목록 (6개)
  [6] 지구의 대기에서 가장 많은 기체는?
선택: 4
최고 점수: 83점 (6문제 중 5문제 정답)
선택: 5
태양계 퀴즈를 종료합니다.
```

두 파일을 바이트 단위로 비교했고 SHA-256 값이 일치했습니다.
